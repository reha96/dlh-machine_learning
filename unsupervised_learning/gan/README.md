# GANs

Generative Adversarial Networks with TensorFlow/Keras: a simple GAN, a
Wasserstein GAN with clipping, a Wasserstein GAN with gradient penalty,
convolutional generator/discriminator for faces, and a pretrained face
generator to play with.

- Task 0: `0-simple_gan.py` — class `Simple_GAN`
- Task 1: `1-wgan_clip.py` — class `WGAN_clip`
- Task 2: `2-wgan_gp.py` — class `WGAN_GP`
- Task 3: `3-generate_faces.py` — `convolutional_GenDiscr`
- Task 4: `4-wgan_gp.py` — `WGAN_GP` with `replace_weights`
